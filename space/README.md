# Sitr AI Gate · سِتر

**Ask Sitr before you ask an AI assistant.** Paste text or attach a PDF, code or text file and
ask "Can I share this?" Sitr answers yes or no in plain Arabic or English, says what it found,
and gives you the version that is safe to send.

![Sitr answering a CV question with a redacted version](docs/images/redact.png)

| Answer | When | What you get |
|---|---|---|
| **Safe** | Nothing personal, confidential or secret | The text, ready to paste |
| **Needs changes** | Names, emails, phone numbers | A redacted version, or a redacted PDF |
| **Keep private** | Salaries, IDs, confidential work | Advice to keep it private, and a redacted version |
| **Don't send** | API keys, passwords, private keys | A version with the secret removed; the secret never reaches a model |

![The Arabic interface: an employment contract is kept private](docs/images/arabic-private.png)

## How it uses Hugging Face

- **Rules** find secrets, IDs, IBANs and salaries in Arabic and English.
- [`OpenMed/privacy-filter-multilingual-v2`](https://huggingface.co/OpenMed/privacy-filter-multilingual-v2)
  finds names and personal data, on CPU inside this Space.
- [`Horizon-Labs/multilingual-zeroshot-small`](https://huggingface.co/Horizon-Labs/multilingual-zeroshot-small)
  reads what the text is about, also inside this Space.
- [`Qwen/Qwen2.5-1.5B-Instruct`](https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct) answers small
  talk through Hugging Face Inference Providers, and runs inside the Space for the private route.
  Every message is checked first: only short small talk with nothing sensitive in it reaches
  Qwen. Files, content pasted under a question, and anything with findings get Sitr's answer
  instead.
- [`arwaili/sitr-synthetic-dlp`](https://huggingface.co/datasets/arwaili/sitr-synthetic-dlp):
  300 synthetic Arabic, English and mixed examples, generated by Qwen in a Hugging Face Job. On its
  held-out test split Sitr picks the right action 95% of the time.

Code, tests and the full write-up: https://github.com/arwaili/sitr-ai-gate

**Use synthetic data only.** This is a security decision-support prototype; the private route is
a demonstration, not an isolated environment. The models load when the Space starts: wait until
the bottom of the sidebar says `Privacy detector ready` before the first request. Built for the
Qai x Hugging Face Hackathon in Qatar by Abdulaziz, Saad, Mohammed and Rashid.
